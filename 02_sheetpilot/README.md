# SheetPilot · Excel AI 处理工具

一个纯前端的本地表格处理工具：导入 Excel / CSV，做常规清洗与统计，并用 AI 做数据体检、分析与出图。
所有解析和计算都在浏览器本地完成，不需要后端；AI 可选接入任意 OpenAI 兼容接口。

## 功能

**表格处理**

- 导入 `.xlsx / .xls / .csv / .tsv`，支持一次多选、拖拽到页面任意位置；CSV 自动识别 UTF-8 / GBK 编码
- 多文件多界面：顶部标签栏切换，每个界面独立保存数据、工作表、筛选、排序、搜索、撤销栈和 AI 对话
- 工作表增删：`+` 新建（和起始页一样是空白面板，可拖文件填入或点「直接录入」），垃圾桶删除（可撤销）
- 编辑：顶部「编辑」开关打开后，单击单元格即可改；关闭时双击改。Enter 确认 / Esc 取消，方向键移动，`Ctrl+V` 整块粘贴
- 行 / 列操作：插入、复制、删除、重命名、列类型识别
- 排序、按列勾选筛选、全局搜索、分页、单元格复制
- 数据体检：空值、重复行、IQR 异常值、健康评分（数据太少的表不打分）
- 一键清洗：去重、删空行、清理空白字符、文本转数字/日期、缺失值填充、异常值处理
- 统计：列分布、快速图表、全表统计
- 导出：当前工作表（含筛选）/ 全部工作表 / CSV，`Ctrl+Z` 撤销最多 20 步

**AI 分析**

- 未配置模型时走内置分析引擎（本地正则路由 + 统计模板）：数据概览、质量诊断、清洗方案、业务洞察、推荐图表
- 配置模型（Base URL / 模型名 / API Key）后走 OpenAI 兼容接口，SSE 流式输出，支持 DeepSeek、Kimi、通义、GLM、OpenAI 等
- AI 给出的清洗方案会变成勾选卡片，确认后一键执行，可撤销
- 切换文件或工作表时 AI 不主动发言；只有提问、点快捷标签或执行方案时才回复

## 运行

**方式一：单文件版（推荐，离线可用）**

直接双击 `SheetPilot.html`，浏览器打开即用（AI 功能需联网）。

**方式二：开发版**

```bash
# 在 02_sheetpilot 目录下起一个静态服务
python -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html
```

> 直接双击 `index.html` 也能跑，但部分浏览器对本地 `file://` 下的脚本加载有限制，推荐用上面的静态服务。

**重新打包单文件版**

```bash
node build.js    # 生成 SheetPilot.html，把 CSS / JS / SheetJS 全部内联
```

```
    └── xlsx.full.min.js    # SheetJS 0.20.3，本地引入，不依赖 CDN
```

## 实现要点

| 主题 | 做法 |
| --- | --- |
| 多界面 | `state.docs[]` + `state.activeDoc`，切换前 `stashDoc()` 把当前状态写回文档，切换时 `activateDoc()` 还原 |
| 撤销 | 每次改动前 `pushHistory()` 做深拷贝快照，最多 20 步，超大表跳过快照 |
| 空状态 | 没有工作表、或工作表还没有数据时，统一渲染起始页的空面板；点「直接录入」才显示空白网格 |
| AI 降级 | `hasKey()` 判断：无 Key 用本地引擎，有 Key 走模型接口；接口失败可回退本地方案 |
| 数据体检 | 只统计「有内容的行」和「用到的列」，少于 3 行不打分，避免新建工作表就提示“建议清洗” |
| 隐私 | 表格只在本机浏览器解析；仅在提问时把数据摘要发送给用户自己配置的模型服务商 |

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + T` | 新建一个空白界面 |
| `Ctrl + O` | 打开文件（可多选） |
| `Ctrl + S` | 导出当前工作表 |
| `Ctrl + F` | 聚焦搜索框 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做 |
| `Ctrl + C` / `Ctrl + V` | 复制选中单元格 / 从选中格开始整块粘贴 |
| `Enter` / `Esc` | 编辑时确认 / 取消；`Esc` 也可退出编辑模式 |

## 浏览器要求

Chrome / Edge / Safari 等现代浏览器（用到 `FileReader`、`fetch` 流式读取、`localStorage`）。
模型配置（Base URL、模型名、Key）保存在浏览器 `localStorage` 的 `sheetpilot.ai.v1` 里，不会上传。
